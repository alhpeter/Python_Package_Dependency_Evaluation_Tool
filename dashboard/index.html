Research method

How IDRF reasons

01 Start with a dependency file Choose a requirements.txt file listing the Python packages the project depends on.

02 Enrich package details Read dependency metadata from PyPI (the Python Package Index, where Python projects publish and share packages) and supplementary public GitHub repository signals.

03 Map the connections Build a bounded dependency graph and calculate structural measurements.

04 Prioritize for review Combine six weighted signals into the Investigative Priority Score (IPS), then surface evidence-backed candidates.
